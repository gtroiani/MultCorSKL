
# Discourse Functional Transcription - adopted conventions

Conventions based on Du Bois et al. 1993 and its subsequent versions (2006, 2020).


| Symbol   | meaning                                | explanation                                                                                                                                         |
| -------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| ,                     | continuing contour               | intonation marks current action as incomplete                                                       |
| ?                     | rising contour                   | marks the use of a rising intonation                                                                |
| .                     | falling contour                  | intonation marks current action as complete (period)                                                |
| -                     | interrupted intonation           | marks intonation unit as interrupted with no discernible contour                                    |
| (.)                   | hold/micropause                  | < 180 milliseconds; brief silence, break in phonation                                               |
| wor-                  | truncated/cut-off word           | word not completed as projected (en dash)                                                           |
| (H)                   | in-breath                        | audible inhalation                                                                                  |
| (Hx)                  | out-breath                       | audible exhalation                                                                                  |
| @                     | laugh                            | one symbol per pulse of laughter                                                                    |
| ###                   | unintelligible                   | one # per indecipherable syllable                                                                   |
| (DESCRIPTION)         | vocalism                         | sound made in vocal tract: (AHEM), (YAWN), etc                                                      |
| (TSK)                 | click                            | alveolar click                                                                                      |
| ¬Jill                 | pseudograph                      | name change (etc.) for anonymity (negation sign)                                                    |
| <VOX word>            | quality = voice of another       |                                                                                                     |
| <READ word>           | quality = reading                |                                                                                                     |
| <SING word>           | quality = singing                |                                                                                                     |
| (EVENT_DESCRIPTION)   | non-vocal event                  | general pattern for acts, events                                                                    |

Du Bois, John W., Stephan Schuetze-Coburn, Susanna Cumming, and Danae Paolino. 1993. “Outline of Discourse Transcription.” In Talking Data: Transcription and Coding in Discourse Research, edited by Jane A. Edwards and Martin D. Lampert. Lawrence Erlbaum Associates Publishers.
